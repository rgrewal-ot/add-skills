# Techniropa ADD skills

Codex skills from the Techniropa ADD programme. One folder per skill, one `SKILL.md` each. Codex reads only `name` and `description` until a task matches, so they cost almost nothing to keep.

| Skill | Use it when |
|---|---|
| spec-refine | you want `spec.md` sharper and on one page; the how moves to `plan-notes.md` |
| grill-me | you want to be interviewed before writing a spec or a plan |
| brainstorming | you want distinct options with trade-offs before deciding |
| issue-writer | you want a spec section or feature sliced into small issues (GitLab, GitHub, Jira) |
| compound-doc | you want to keep what a thread taught you, and get proposed `AGENTS.md` lines |
| ramble-to-feature | you talked for five minutes and want a feature description out of it |
| ramble-to-todo | you talked for five minutes and want a to-do list out of it |
| mail-formulator | you want an email in your team's tone from rough notes |

## Into your team repo (recommended)

Copy the folders you want into `.agents/skills/` in your team repo and commit. Every teammate gets them with the next pull. In Codex:

```
"Copy the folder spec-refine from <this repo> into .agents/skills/ and commit."
```

Check with `/skills`. Use with `$spec-refine`, or just describe the task and let Codex pick the skill by its description.

## Only for yourself

Copy a folder into `~/.agents/skills/` (Windows: `%USERPROFILE%\.agents\skills\`). It then works in every project on your laptop, for nobody else.
